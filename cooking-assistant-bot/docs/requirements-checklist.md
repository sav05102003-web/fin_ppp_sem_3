# Соответствие требованиям

## Тема 4 — кулинарный помощник

| Требование | Реализация | Проверка |
| --- | --- | --- |
| Рецепты по ингредиентам | `/find`, синонимы, ранжирование и карточки `/recipe` | Поиск, совпадения, сохранённые продукты |
| Меню на неделю | `/plan авто`, ручная замена, 7 × 3 приёма пищи | Все типы питания, подходящий приём, порции |
| Список покупок | `/shopping`, сумма количеств, `/buy` | Пересчёт, объединение, переключение отметки |
| Таймеры готовки | `/timer`, `/timers`, `/cancel_timer`, JobQueue | Границы, отмена, доставка, восстановление и повторы |
| Диетические рекомендации | `/diet`, `/exclude`, `/tips` | Фильтрация, предупреждения и сброс неподходящего меню |

## Общие требования

| Требование | Выполнение |
| --- | --- |
| Публичный GitHub-репозиторий | `sav05102003-web/fin_ppp_sem_3`, папка `cooking-assistant-bot` |
| Использование venv | Создано настоящее окружение Python 3.12.14; тесты запущены его интерпретатором |
| Не добавлять `venv/` в `.gitignore` | Каркас `venv/` сохранён; библиотечный каталог `site-packages/` восстанавливается из зависимостей |
| Версии библиотек | `requirements.txt` и `requirements-lock.txt` |
| Первый коммит — README и имя студента | Первый коммит этой работы: `Стрельцов Андрей`, только README |
| Не менее четырёх коммитов | Пять содержательных этапов, включая первый README |
| Обоснование структуры | Раздел «Структура проекта» в README |
| PEP 8 и PEP 257 | `pycodestyle`, `pydocstyle`, документированные классы и публичные методы |
| README на русском с установкой и примером | Все обязательные разделы включены |
| Docker | Не добавлен: необязательный пункт |

README содержит автора и группу, подтверждённые пользователем,
дату, описание, основные и дополнительные функции, системные требования,
установку для трёх ОС, настройку токена, команды, дерево модулей,
обоснование структуры и воспроизводимый пример использования.
Скриншоты необязательны; вместо них включён текст реального запуска
`python main.py --demo`.

Внесение ссылки в учебную Google-таблицу «Репозитории» исключено
пользователем из текущего задания. Приёмочные испытания в живом Telegram
требуют токена собственного бота от BotFather.
