## Описание проекта

Telegram-бот подбирает рецепты по продуктам, составляет меню на неделю
и рассчитывает список покупок. Помогает учитывать пищевые предпочтения
и следить за временем приготовления с помощью сохраняемых таймеров.

## Функциональные возможности

### Основной функционал

- Поиск рецептов по ингредиентам и просмотр пошаговых инструкций.
- Планирование завтраков, обедов и ужинов на семь дней.
- Список покупок с пересчётом количества на выбранные порции.
- Таймеры готовки с уведомлениями в Telegram.
- Выбор типа питания и исключение нежелательных ингредиентов.

### Дополнительный функционал

- Сохранение личных данных в SQLite и восстановление после перезапуска.
- Кнопки главного меню и подсказки команд.
- Демонстрация без токена и подключения к Telegram.
- Автоматические проверки логики и обработчиков.

Подробная инструкция запуска, команды и результаты проверок будут
добавлены вместе с реализацией следующих этапов.
