## Описание проекта

Программа открывает окно 600×600 пикселей, целиком заполненное областью
рисования Canvas. В центре находится окружность радиусом 200 пикселей,
по которой движется точка. По умолчанию движение идёт по часовой стрелке;
одна переменная `SPEED` задаёт угловую скорость и направление.

## Функциональные возможности

### Основной функционал

- Окно с рабочей областью ровно 600×600 пикселей.
- Окружность с центром (300, 300) и радиусом 200 пикселей.
- Непрерывное движение точки по окружности по часовой стрелке.
- Изменение скорости и направления через `SPEED` в `main.py`.

### Дополнительный функционал

- Изменение скорости и направления с клавиатуры без перезапуска.
- Пауза, продолжение и возврат точки в начальное положение.
- Текущая скорость и состояние в заголовке окна, справка по F1.
- Скорость зависит от прошедшего времени, а не количества кадров.
- Автоматические проверки геометрии, движения и интерфейса.
- Отдельный пример из методических указаний: `examples/intro.py`.

## Требования к системе

- **Python:** 3.10 или выше с поддержкой Tcl/Tk.
- **Операционная система:** Windows, macOS или Linux с графическим рабочим столом.
- **Зависимости:** только стандартная библиотека Python: `tkinter`, `math`,
  `time`, `dataclasses`, `unittest` и `pathlib`.

`tkinter` не устанавливается через pip. В официальном установщике Python
для Windows включите компонент Tcl/Tk; в Debian/Ubuntu при необходимости
установите `python3-tk` и `python3-venv`. Проверка установки:

```bash
python -m tkinter
```

Должно открыться тестовое окно Tk. На macOS/Linux вместо `python` можно
использовать `python3`.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/sav05102003-web/tkinter-circle-motion.git
cd tkinter-circle-motion
```

### 2. Создание и активация виртуального окружения

По условию работы каталог `venv/` сохранён в Git и не включён в `.gitignore`.
Виртуальные окружения содержат пути к локальному Python и не переносятся
между компьютерами. После клонирования пересоздайте окружение своей
установкой Python; `--clear` очищает только каталог `venv`.

**Windows PowerShell:**

```powershell
python -m venv --clear venv
.\venv\Scripts\Activate.ps1
```

**Windows cmd:**

```bat
python -m venv --clear venv
venv\Scripts\activate.bat
```

Если PowerShell запрещает запуск сценария активации, можно использовать
интерпретатор напрямую, без изменения настроек системы:

```powershell
.\venv\Scripts\python.exe main.py
```

**macOS/Linux:**

```bash
python3 -m venv --clear venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

Файл содержит только комментарии о Python и tkinter: сторонних пакетов нет.
Сохранённое учебное окружение создано с `--without-pip`, поскольку программе
pip не требуется. При его использовании установите pip командой
`python -m ensurepip` либо пересоздайте окружение по инструкции выше.

### 4. Запуск программы

```bash
python main.py
```

Выполняйте команды из каталога проекта. Для проверки примера из методички:

```bash
python examples/intro.py
```

### 5. Управление

| Клавиша | Действие |
| --- | --- |
| Пробел | Пауза / продолжение |
| ↑ | Увеличить модуль скорости на 0,25 рад/с |
| ↓ | Уменьшить модуль скорости на 0,25 рад/с, вплоть до остановки |
| → | Движение по часовой стрелке |
| ← | Движение против часовой стрелки |
| R (или К в русской раскладке) | Вернуть точку наверх, сохранив скорость и паузу |
| F1 | Открыть справку |
| Esc | Закрыть программу |

Чтобы клавиши работали, выберите окно программы. При нулевой скорости
стрелки ← / → запускают движение со скоростью 0,25 рад/с.

## Настройка скорости

В начале `main.py` задаётся одна переменная:

```python
SPEED = 1.0  # рад/с: плюс — по часовой, минус — против часовой
```

- `SPEED = 1.0`: полный оборот примерно за 6,28 секунды по часовой стрелке.
- `SPEED = -2.0`: полный оборот примерно за 3,14 секунды против часовой.
- `SPEED = 0.0`: точка неподвижна, интерфейс продолжает работать.

После изменения файла перезапустите программу. Дробные числа в Python
записываются через точку.

## Пример использования

1. Запустите `python main.py`: точка начнёт движение от верхней части
   окружности по часовой стрелке со скоростью 1 рад/с.
2. Нажмите ↑ два раза: скорость станет 1,5 рад/с.
3. Нажмите ←: скорость станет −1,5 рад/с, направление изменится.
4. Нажмите Пробел: точка остановится на текущем месте.
5. Нажмите R: точка вернётся в (300, 100), оставаясь на паузе.
6. Снова нажмите Пробел для продолжения, Esc — для выхода.

## Как работает анимация

Координаты точки вычисляются по формулам:

```text
x = 300 + 200 · cos(φ)
y = 300 + 200 · sin(φ)
φ = (φ + SPEED · Δt) mod (2π)
```

Начальный угол равен −π/2, поэтому точка находится наверху окружности.
В Canvas ось Y направлена вниз: увеличение угла даёт движение по часовой
стрелке. Знак `SPEED` задаёт направление, модуль — угловую скорость.

`time.perf_counter()` измеряет фактическое время между кадрами. Следующий
кадр назначается через `after(16, ...)`, а `mainloop()` обрабатывает события.
Во время паузы время отсчитывается, но угол не изменяется, поэтому после
продолжения точка не перескакивает вперёд. Существующий объект Canvas
перемещается через `coords()`, новые точки каждый кадр не создаются.

## Проверка работы

В активированном окружении выполните:

```bash
python -m unittest discover -s tests -v
```

Проверки модели охватывают радиус, центр, направление, период, изменение
скорости, остановку, сброс и некорректные числовые значения. Проверки GUI
открывают настоящее окно и проверяют размеры, Canvas, таймер и клавиши.
Без графического рабочего стола проверки GUI пропускаются с указанием
причины; проверки модели продолжают работать.

Ручная проверка: убедитесь, что окно имеет рабочую область 600×600,
окружность касается координат 100 и 500 по каждой оси, точка следует по
линии окружности, а пауза, смена направления и закрытие работают.

## Ответы на контрольные вопросы

**Зачем нужна библиотека tkinter?** Для создания графических приложений:
окон, кнопок, полей ввода, меню и обработки действий пользователя.
Это стандартный интерфейс Python к Tcl/Tk.

**Что такое Canvas?** Виджет — область рисования, на которой можно создавать
линии, окружности, прямоугольники, текст и изображения. Созданные объекты
имеют идентификаторы, по которым меняют их координаты и свойства.

**Как работает анимация?** Программа периодически пересчитывает положение
объекта и обновляет его координаты. `after()` планирует следующий кадр,
оставляя цикл обработки событий свободным для клавиатуры и закрытия окна.
