## Описание проекта

Приложение на Python и tkinter рекурсивно строит кривую Гильберта и
постепенно рисует её с плавным изменением цвета вдоль линии. Пользователь
может выбирать число итераций, скорость и другую кривую, заполняющую
плоскость. Анимация начинается с небольшой глубины рекурсии.

## План разработки

1. Структура проекта и виртуальное окружение.
2. Рекурсивные алгоритмы и модель анимации.
3. Отрисовка, окно и интерактивное управление.
4. Дополнительная кривая и её демонстрация.
5. Проверки и полная документация.

Проект размещается в папке `hilbert-curve` публичного репозитория
[fin_ppp_sem_3](https://github.com/sav05102003-web/fin_ppp_sem_3).
