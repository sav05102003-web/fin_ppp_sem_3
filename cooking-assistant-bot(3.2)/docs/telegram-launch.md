## Проверить основные функции

Откройте [бота в Telegram](https://t.me/andrey_cooking_helper_bot)
и отправьте команды последовательно.

| Шаг | Команда | Ожидаемый результат |
| --- | --- | --- |
| Главное меню | `/start` | Справка и кнопки «Рецепты», «Меню», «Покупки», «Таймеры», «Питание», «Помощь» |
| Продукты | `/find рис, морковь, перец` | Подходящие рецепты и список недостающих ингредиентов |
| Приготовление | `/recipe 3` | Рис с овощами: состав, порции и пошаговый рецепт |
| Питание | `/diet веганское`, затем `/tips` | Подтверждение предпочтения и подходящие блюда |
| Недельное меню | `/plan авто 2` | 21 запись: семь дней по три приёма пищи на две порции |
| Покупки | `/shopping`, затем `/buy 1` | Суммарные количества продуктов и отметка первой покупки |
| Таймер | `/timer 10с чай` | Подтверждение таймера, затем уведомление о завершении |

Настройки и данные каждого человека сохраняются отдельно.
Смена питания сбрасывает меню: сначала выберите `/diet`, затем `/plan`.

## Доступность

Ссылка открывает действующую учётную запись бота. Ответы и уведомления
доступны, когда приложение запущено и компьютер подключён к интернету.
Круглосуточный сервер и автоматический запуск после перезагрузки
пока не настроены. При остановке приложения данные сохраняются в SQLite;
просроченные таймеры обрабатываются после следующего запуска.

Токен хранится в локальном `.env`. Этот файл, личная база данных
и журналы работы исключены из Git. Для собственного экземпляра создайте
отдельного бота у [@BotFather](https://t.me/BotFather) и выполните
[инструкцию установки](../README.md#установка-и-запуск).
